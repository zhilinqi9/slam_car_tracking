# SOP 00 安全规范（任何上车操作之前必读）

底盘 30 kg，速度最高 1.5 m/s（5.4 km/h），**自身不带自动防撞**（手册"重要安全信息"一节）。

## 1. 每次上车前
- [ ] 电量 ≥ 30%（`/chassis/state` 或遥控器 Ext.V 项，单位显示为 V，实际是 %）
- [ ] 尾部急停旋钮已释放，人站在随手能拍到它的位置
- [ ] **遥控器开机并拿在手上**。遥控器优先级最高：把 SWA 拨上去就立即回到遥控模式，这是最快的接管方式
- [ ] 遥控器所有拨杆都在默认位置（向上），否则开机会报警
- [ ] 场地清空，周围 1 m 内没有人站在车的行进方向上

## 2. 新代码第一次运行
1. **架空**：用支架把车垫起来，四个轮子离地（手册 4.5 节 1.6 条）
2. 限速参数先设为最小（如 `max_vx: 0.2`、`max_wz: 0.3`）
3. 架空运行正常后再放到地面，先以低速跑短距离
4. 验证"断开上游 → 停车"：杀掉 `/cmd_vel` 的发布者，车应在 0.3 s 内停下

## 3. Claude Code 与机器人运动
- Claude **不能自己发起任何让车动的命令**（`rostopic pub /cmd_vel`、`cansend`、启动 repeat/navigation 相关 launch）。`.claude/settings.json` 已把这些命令设为每次都要人工确认
- 人工确认之前先看三件事：车是否架空或场地是否清空、遥控器是否在手、限速是多少
- 运动测试由**人**来执行，Claude 负责准备命令、录 bag、分析数据

## 4. 出现异常
- 先拍急停或拨 SWA，再排查原因
- 底盘报故障（`error_fb` 等级 E2/E3）时停止测试，记下故障码并查手册的故障编码表
- 低电量报警时立即停止，按手册 4.2 节的顺序充电（先插车端，再插 AC）
