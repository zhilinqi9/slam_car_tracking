# 操作说明（SOP）索引

SOP 是**累积型**文档：每个阶段验收通过后，把"现在应该怎么操作"写进对应的 SOP。工作日志记录的是"那天发生了什么"，SOP 记录的是"现在该怎么做"。
如果 SOP 和代码对不上，以代码为准，并在当天的工作日志里记下来，然后修正 SOP。
