## 4. 问题与根因（详见评估报告）
- **现象**：v1 建图有重影，导航跟不住路径，也不避障
  **根因**（代码审查确认，未上车复现）：
  1. 底盘是 4T4D，6 档会丢弃 vy，但 DWA 按全向底盘配置（K1）
  2. `odom→base_link` 被 EKF 和 RTAB-Map 视觉里程计重复发布（L1），RTAB-Map 被启动了两次（L2）
  3. costmap 的障碍层参数命名空间写错，障碍层为空（N1），观测源只有约 1 Hz（N2）
  4. 只有一个前向深度相机，定位鲁棒性有物理上限（L4）
- **现象**：工作日志里的代码和仓库代码对不上（`invert_angular`、50 Hz 等）
  **根因**：日志里写的是"示意代码"，没有对应的 commit
  **处置**：CLAUDE.md 规定日志只能引用 commit 和实测数据；`angular_sign` 留到 P1 上车标定
- **手册勘误**：4.5 节 steering_ctrl_cmd 示例表格的 ID 列印成了 `0x18C4D1D0`，按协议表应为 `0x18C4D2D0`（数据字节本身无误，已在测试注释中说明）
