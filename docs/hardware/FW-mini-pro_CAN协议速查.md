# FW-mini-pro CAN 协议速查

> 来源：《FW-mini-pro 用户使用手册 V1.1.1》4.4 / 4.5 节（PDF 在本地 `6-煜禾森商业导航/`，不入库）。
> 代码实现：[`ros_ws/src/fw_chassis/include/fw_chassis/protocol.hpp`](../../ros_ws/src/fw_chassis/include/fw_chassis/protocol.hpp)，测试向量取自手册示例帧。

## 总线
- CAN 2.0B **扩展帧**，**500 kbps**，Intel（小端）排列
- SocketCAN 发送时 `can_id = ID | CAN_EFF_FLAG`（旧驱动里的 `0x98C4D1D0` 就是 `0x18C4D1D0 | 0x80000000`）
- 每个控制帧都要带：Byte6 高 4 位（bit52–55）**Alive Rolling Counter**（每帧加 1，0–15 循环），Byte7 = **Byte0 ⊕ … ⊕ Byte6**
- 控制帧周期 **10–50 ms**；超时后底盘心跳保护会停车

## 底盘参数
| 项 | 值 |
|---|---|
| 结构 | 四转四驱（4T4D），四轮独立驱动 + 独立转向 |
| 外形 | 565 × 380 × 255 mm，30 kg，载重 40 kg |
| 轴距 / 轮距 | 360 mm / 280 mm |
| 轮径 | 140 mm（5.5 寸） |
| 最高速度 | 5.4 km/h = 1.5 m/s |
| 最小转弯半径 | 0（手册标称；6 档下能否原地旋转待 P1 实测） |
| 对外供电 | 12 V / 15 A，24 V / 10 A（顶部电气板 1,2 = 12 V+；3,4 = 24 V+；9,10,15 = GND） |
| CAN 接口 | 顶部电气板 13 = CAN-H，14 = CAN-L |
| 编码器 | 单圈 4096 × 减速比 个脉冲 |

## 控制帧

### ctrl_cmd `0x18C4D1D0`（导航使用这一帧）
| 信号 | 起始位 | 长度 | 类型 | 分辨率 | 说明 |
|---|---|---|---|---|---|
| 档位 | 0 | 4 | u | 1 | **0 disable · 1 驻车 · 2 空档 · 6 4T4D · 8 横移** |
| X 线速度 | 4 | 16 | s | 0.001 m/s | 向前为正；6/8 档有效 |
| Z 角速度 | 20 | 16 | s | **0.01 °/s** | **俯视逆时针为正**；仅 6 档有效 |
| Y 线速度 | 36 | 16 | s | 0.001 m/s | 向左为正；仅 8 档有效 |
| Alive | 52 | 4 | u | | |
| BCC | 56 | 8 | u | | |

> **6 档只认 vx + wz，8 档只认 vx + vy。两种档位都不是全向底盘。**

### steering_ctrl_cmd `0x18C4D2D0`（虚拟转向轮 / 自行车模型）
档位：0/1/2 同上，**5 = 4T4D，7 = 横移**（注意和 ctrl_cmd 的取值不同）；虚拟转向轮速度（bit 4，0.001 m/s）；虚拟转向轮角度（bit 20，0.01°，向左为正）。

### io_cmd `0x18C4D7D0`
bit0 灯控制权 · bit1 **安全停车解锁（下降沿有效）** · bit2 低功耗使能 · bit8 近光灯 · bit10–11 转向灯 · bit12 制动灯 · Byte2 低功耗触发比例。

## 反馈帧
| ID | 名称 | 周期 | 内容 |
|---|---|---|---|
| `18C4D1EF` | ctrl_fb | 10 ms | 布局同 ctrl_cmd：档位、vx、wz（°/s）、vy |
| `18C4D2EF` | steering_ctrl_fb | 10 ms | 档位、虚拟轮速度、角度 |
| `18C4D6EF` / `D7` / `D8` / `D9` | 左前 / 左后 / 右后 / 右前轮 | 10 ms | 速度 s16（0.001 m/s）@bit0，脉冲 s32 @bit16 |
| `18C4DAEF` | io_fb | 50 ms | bit24–29 防撞条（前左/中/右、后左/中/右）；**bit40 急停**；**bit41 遥控器控制状态**；bit42 充电桩；bit43 手动充电；bit45 遥控在线 |
| `18C4DCEF` / `DDEF` | 前 / 后轮转向角 | 10 ms | 左、右各 s16，0.01° |
| `18C4E1EF` | bms_fb | 100 ms | 电压 u16 0.01 V；电流 s16 0.01 A；剩余容量 u16 0.01 Ah |
| `18C4E2EF` | bms_flag_fb | 100 ms | SOC u8 %；保护位；最高 / 最低温度 s12 0.1 ℃（@bit28 / @bit40） |
| `18C4E3EF` / `E4EF` | 驱动 / 转向电机电流 | 100 ms | 4 × s12 0.1 A + 堵转标志 |
| `18C4E8EF` / `E9EF` | 前 / 后超声波 | 50 ms | 4 × u12 mm；200 = 盲区，2540 = 超量程，2560 = 无探头 |
| `18C4EAEF` | error_fb | 100 ms | 等级（0 / E1 / E2 / E3）、部件类型、部件 id、故障码、寄存器 |

## 遥控器与控制权
- **SWA**：上 = 遥控模式，下 = 指令（CAN）模式。两者都在时**遥控器优先**
- **SWB**：上 = 驻车，中 = 4T4D（双阿克曼），下 = 横移
- **VRB**：必须按住，摇杆才有效
- **VRA**：碰到防撞条触发安全停车后，拨一下解除（也可以通过 io_cmd 的 unlock 位解除）

## 手册示例帧（单元测试向量）
```
4T4D  vx=0.5 wz=-25°/s : 46 1F C0 63 0F 00 10 E5  (alive=1)
横移  vx=0.3 vy=-0.3    : C8 12 00 00 40 ED 4F 38  (alive=4)
反馈  同 4T4D 例         : 46 1F C0 63 0F 00 A0 55  (alive=A)
```
