按以下步骤执行，最后用中文汇报：

1. 读 `CLAUDE.md`，以及 `docs/worklog/` 下**最新的两篇**日志（按文件名排序），重点看"下次计划"和"遗留问题"
2. 读 `docs/01_技术路线与里程碑.md`，确定当前阶段（第一个还有未勾选条目的 P 阶段）
3. 执行 `git status --short`、`git log --oneline -10`、`git branch -a`、`git worktree list`
4. 如果当前在 Jetson 上（存在 `/etc/nv_tegra_release`），执行 `./tools/check_env.sh` 并汇总异常项
5. 结合用户的输入：$ARGUMENTS

汇报格式：
- **当前状态**：处于哪个阶段、上次停在哪里、有哪些未提交的改动
- **今天的任务**（3–5 项）：每项写明 ①产出物 ②验收方式（测试 / 指标 / 现象）③是否需要上车（需要的话，写明架空还是落地）
- **可以并行的任务**：哪些任务互不相关，可以放进不同的 worktree 或交给子代理（参考 `docs/02_ClaudeCode工作流.md`）
- **需要用户准备的东西**：硬件、场地、遥控器、电量

先不要动手改代码，等用户确认计划。
